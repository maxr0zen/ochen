01 / замысел

Локальный смысловой поиск по именам, тегам и метафорам. Без внешней AI-модели.

AI-композиция · Gemini / Groq

AI предлагает расположение. Исходные SVG и общий масштаб проверяет конструктор. Нужен локальный сервер: npm run ai.

Сервер ещё не подключён

Названия, теги и размеры отправляются выбранному провайдеру. Миниатюры — только при включённой опции. SVG-контуры модель не редактирует.

Размер S/L выбирает исходные варианты, а не масштаб. Относительные размеры предметов сохраняются. Состояние каждого экземпляра можно изменить после сборки.
