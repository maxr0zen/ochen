# Правила смысловой расстановки

Локальный компоновщик использует `src/scene-rules.ts`. Правила применяются после начального размещения и до окончательного вписывания группы в холст. Нейросеть, API и интернет для этого не нужны.

| Связь | Поведение |
| --- | --- |
| Лампа → цель | Выбирается книга, пазлы, папка или другой подходящий предмет. Лампа располагается так, чтобы нужная точка объекта была перед плафоном, внутри условного конуса света |
| Монеты → кошелёк | Монеты собираются рядом с кошельком. Если кошельков несколько, группы распределяются между ними |
| Монеты → книга | Если кошелька нет, монеты связываются с книгой. Если нет обоих предметов, монеты группируются между собой |
| Ручка → поверхность | Наконечник направляется на страницу книги, папку или пазлы. Контуры ручки не поворачиваются независимо от её частей |
| Телефон ↔ наушники | Предметы располагаются рядом как одна смысловая группа; центр экрана не прячется за наушниками |
| Порядок слоёв | Фоновые варианты позади главных; бумажные поверхности под мелкими предметами; монеты и ручка впереди |

## Направление лампы

В исходных иллюстрациях плафон смотрит вправо-вниз. Для S/L заданы нормализованные положение отверстия плафона и направление его оси. Цель располагается по этой оси; допустимый конус — ±20°. Положение предметов можно менять, отражать сами исходники нельзя. Поэтому после изменения seed направление лампы пересчитывается, а не зеркалится вместе с расстановкой. Seed также меняет расстояние внутри допустимой композиции, сохраняя связь.

Конус существует только в расчёте: лучи, новые формы и новые иллюстративные объекты в SVG не добавляются. Это композиционная модель, а не физический симулятор освещения. Якоря откалиброваны под текущие исходные иллюстрации; при замене рисунков их необходимо проверить заново.

Если у лампы нет цели, состав запроса сохраняется и показывается предупреждение. Другой предмет автоматически не добавляется. Порядок выбора целей и якоря редактируются централизованно в `SCENE_RULES` и таблице `surface`.

## Ручные правки

В панели отображаются «Связи предметов». По умолчанию это связи созданного варианта. После ручного перемещения нажмите «Проверить связи на холсте»: проверка читает актуальные трансформации Figma и сообщает о нарушениях. Она не перемещает объекты автоматически. Пересборка создаёт новый вариант с правилами рядом с предыдущим.

Общий масштаб, геометрия исходников и ограничения палитр остаются обязательными. Правила не растягивают отдельные предметы и не меняют их внутренние элементы. Отдельный AI-режим не используется локальным компоновщиком и не нужен для этих связей.

## Проверки

Проверены S/L, три схемы, квадратный/альбомный/портретный форматы и чётные/нечётные seed. Проверяются направление света, выход за холст, несколько ламп/целей, отсутствие незаказанных объектов, распределение монет, ручка на поверхности, связь телефона и наушников. Отдельно проверяется обнаружение неверного положения после ручной правки.

Отчёт по сохранённым примерам — `output/composition-v3/rules-validation.json`. Внутренняя SVG-геометрия проверяется отдельно в `geometry-validation.json`. Старый нативный отчёт v2 не считается новым прогоном этих правил.
