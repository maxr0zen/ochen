# Использованные инструменты

AI-инструмент разработки — **Codex**: анализ ТЗ, архитектура, TypeScript/HTML/CSS, отладка, тесты и документация. Генерация новых иллюстративных объектов не применялась.

Рабочие инструменты и навыки:

- **agent-desktop 1.1.0**, встроенные инструкции desktop/Windows: запуск и проверка плагина в настольной Figma, семантические действия с панелью и чтение фактического отчёта. `--headed`, физическая мышь и синтетические клавиши не использовались. Figma иногда сама активировалась после действий; полная изоляция фокуса приложения не гарантируется.
- **Chrome DevTools**: чтение исходного Figma-файла с доступом на просмотр, штатная команда Copy as SVG. Скрытые внутренние API документа не использовались.
- **computer-use** применялся на раннем этапе регистрации. Недоступные системные диалоги подтверждал пользователь. Позднее работа переведена на agent-desktop по его просьбе.
- **design-taste-frontend**: компактная панель конструктора, направление Framed sheet, системный шрифт для работы без сети.
- **systematic-debugging**: разбор ошибок экспорта, передачи палитры и численных погрешностей при масштабировании Figma.
- **verification-before-completion**: типизация, тесты и реальные проверки Plugin API перед заявлением о готовности.
- **Playwright / headless Chrome**: тесты панели и SVG-валидатора, проверка экспортов, сравнение исходных SVG и снимки результатов.
- **Figma Plugin API**, TypeScript, esbuild, fflate: векторное копирование и экспорт, сборка и упаковка проекта.

Навык figma-use был изучен для возможного доступа к источнику, но запись через MCP в исходный файл недоступна с правами на просмотр. Работающий конструктор не зависит от MCP и его лимитов. Отдельные AI-агенты и внешняя модель для генерации SVG не запускались. Технические SVG-фикстуры отделены от настоящей библиотеки.

## AI во время работы продукта

Внешняя модель не подключена. Метафоры анализируются локальным словарём понятий и тегами исходных предметов с объяснением выбора. Словарь расширяется в коде и метаданных; произвольный незнакомый запрос может быть отклонён. Через структурированный план разрешено передать выбор от внешней модели, но только существующие assetId. Новые пути и предметы такой план не создаёт.

Код и подготовленная библиотека доступны в [репозитории](https://github.com/maxr0zen/ochen).

При завершающей нативной проверке по отдельному разрешению владельца Figma временно выведена на передний план: в скрытом окне SVG-экспорт и таймеры переставали продвигаться. Фокус переключался командой agent-desktop; мышь и клавиатура не использовались.

## Подготовленный AI-режим v0.4

Добавлены адаптеры Gemini/Groq и локальный сервер, но запросы к настоящим моделям ещё не выполнялись: владелец не предоставил ключ. AI не использовался для создания сохранённых примеров v3. API-контракты проверяются тестовыми ответами. При включении пользователем AI-режим может анализировать метафору, размеры и добровольно переданные миниатюры; возвращает только JSON размещения. См. AI-SETUP.md.
