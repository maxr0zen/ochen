# Короткая демонстрация

Откройте `demo/showcase.html`. Три готовые композиции видны сразу. К каждой приложены редактируемый SVG и параметры сцены. Новые сцены собираются внутри Figma.

Показ конструктора, около двух минут:

1. Запустите локальный плагин. Каталог подготовится автоматически: 10 предметов, два уровня детализации, два состояния.
2. «Из компонентов» → `книга, монета × 2, лампа` → S → квадрат → сиреневая схема → «Собрать композицию».
3. Поверните предмет, продублируйте монету и измените порядок слоёв на холсте. Кнопкой состояния замените главный вариант на исходный фоновый.
4. «По метафоре» → `Идеи для команды` → L → альбом → главные и фоновые → персиковая схема. Соберите новый вариант.
5. Загрузите `palettes/ink-mint.json`, посмотрите предпросмотр и примените. Верните исходную схему.
6. Скачайте SVG и нажмите «Проверить SVG в Figma». Результат повторного импорта должен содержать векторные узлы и группы.

Для воспроизведения приёмки откройте «Проверка библиотеки и примеры» → «Проверить библиотеку». Плагин проверит каждый из 40 вариантов, матрицу из 54 сочетаний и ограничения редактирования, затем создаст три примера. Кнопка «Скачать три примера» сохранит SVG, JSON сцен и происхождение в ZIP.

Для быстрого показа используйте «Собрать три примера»: она работает независимо от тестового прогона. Если часть проверок получила ошибку экспорта Figma, доступен точечный повтор с сохранением истории.

Видео не записывалось. Демонстрация представлена интерактивным локальным обзором, тремя настоящими SVG и сценарием воспроизведения в работающем плагине.

Демонстрационный `demo/index.html` теперь самодостаточен в части картинок и скачивания примеров: его можно открыть отдельно от остальных папок. Исходник страницы — `demo/template.html`. После изменений выполняйте `npm run demo:build`; регрессионная проверка — `npm run demo:check`.
