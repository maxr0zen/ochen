# Происхождение библиотеки

Источник: https://www.figma.com/design/4MCFttsSoP7hgQh29zq5G3/ («Тестовое | иллюстрации»), страница «Библиотека компонентов». Секции S — `21:25859`, L — `21:25788`.

Из исходного файла с доступом на просмотр штатной командой Copy as SVG скопированы целые секции S/L. Их неизменённые экспорты сохранены в `source-library/source-S.svg` и `source-library/source-L.svg`. Исходный документ не редактировался.

В каждой секции есть 10 предметов: книга, телефон, пазлы, монета, наушники, лампа, цветы, кошелёк, папка и ручка. Каждый имеет главный и фоновый вариант. Итого 20 главных иллюстраций S/L и 20 соответствующих фоновых вариантов, 40 SVG-файлов. S/L — уровни исходной детализации.

`scripts/prepare-library.mjs` извлекает существующие узлы SVG по расположению и порядку исходных фигур. Сохраняются path-данные, трансформации, служебные определения и порядок подслоёв. Добавляется только контейнер предмета и его система координат. Учитывается отдельный тонкий штрих монеты, который иначе выпадал из пространственной группировки. Хеши исходных секций и каждого результата, границы и число фигур записываются в `library/manifest.json`.

Дополнительно пять целых предметов независимо скопированы из Figma: два состояния цветов, два состояния монеты и фоновая папка (`source-library/L-01.svg` … `L-05.svg`). `scripts/verify-library.mjs` сравнивает извлечённые предметы с этими контрольными копиями по видимым границам и пикселям. Результат — `output/library/validation.json`. Проверены пять контрольных предметов; попиксельного сравнения всех 40 с независимыми экспортами не выполнялось.

Три исходные цветовые схемы выписаны из настоящих образцов: `source-library/palette-swatches.json`. Каждая хранит четыре фоновых и четыре объектных слота. Фоновые варианты исходника монохромны; объектные цвета в них не подставляются. Белые заливки служебных масок не перекрашиваются.

Для повторной подготовки нужны установленные зависимости и Google Chrome:

```sh
node scripts/prepare-library.mjs
node scripts/verify-library.mjs
```

Результат включён в локальный проект для запуска без доступа к исходному Figma-файлу.
