# Соответствие полной версии ТЗ

Версия проекта 0.3.0. Состояние проверяется кодом, настоящими исходными SVG и исполнением Figma Plugin API. Численные результаты приведены в `ACCEPTANCE.md` и машинных отчётах.

| Требование | Реализация |
| --- | --- |
| Допустим Figma-плагин | Автономный development-плагин с готовой сборкой и инструкцией |
| Только элементы исходных 20 иллюстраций | 10 предметов × S/L, главные и исходные фоновые варианты; 40 утверждённых SVG с происхождением и хешами |
| Метафора/заголовок → композиция | Локальный словарь понятий и теги, объяснения выбора; неизвестный смысл отклоняется |
| Названия компонентов → композиция | Имена, синонимы, количества, явное фоновое состояние; автоматическое разрешение выбранных S/L |
| SVG и сохранение векторной структуры | Копирование исходных path и групп, векторные узлы Figma; растр и текст отклоняются |
| Размер S/L по детализации | Два исходных набора, самостоятельный переключатель, соответствующий вариант подставляется автоматически |
| Перенос, поворот, дублирование, удаление, слои | Штатные операции Figma, текущее состояние учитывается при экспорте |
| Комбинации из нескольких исходников | Компоновка нескольких семей предметов в одном фрейме |
| Разные форматы | Квадрат, альбом, портрет и собственные размеры |
| Сохранение пропорций предметов друг относительно друга | Единый масштаб всей сцены; независимое растяжение/масштабирование предмета блокирует экспорт |
| Главные и фоновые объекты | Главные, смешанные и фоновые композиции; замена каждого экземпляра цельным соответствующим вариантом |
| Три схемы и расширение | Три настоящие палитры источника, импорт дополнительных JSON-схем |
| Автоматическая перекраска | Точное сопоставление четырёх фоновых и четырёх объектных цветовых ролей |
| Фоновые цвета допускаются в предметах, обратное запрещено | Главным доступно объединение палитр; фоновым только фоновые слоты; проверка перед экспортом |
| Объект и внутренние элементы не меняются | Клонируется целый вариант; сравнение нормализованной геометрии с источником |
| SVG скачивается и остаётся редактируемым | Экспорт групп и путей, XML-проверка, повторный импорт и экспорт в настоящей Figma |
| Работающий запускаемый проект и короткая демонстрация | manifest + dist; `demo/index.html`, три SVG, сценарий показа |
| Описание архитектуры и AI-инструменты | README, SOURCE-AUDIT, AI-TOOLS |
| 2–3 примера | Три финальных примера в `examples/v3/` с параметрами и происхождением |
| Ссылка на исходный репозиторий | [maxr0zen/ochen](https://github.com/maxr0zen/ochen) |

Поиск метафор не является универсальной языковой моделью: работает на размеченных понятиях исходной библиотеки. ТЗ допускает AI-анализ метафор, но не требует внешней модели. Для проверки запуска не нужен доступ к платному API или Figma MCP.

Старые примеры и отчёты v1 относятся к прототипу до расширенного ТЗ. Приёмочными считаются только v2; архив доставки не включает устаревшие примеры.
